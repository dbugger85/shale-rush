# Shale Rush

A phone-friendly game about shale oil fracking. Drill down, steer sideways into the oil shale, place charges, frack the rock and pump out as much oil as you can for the biggest profit.

Play: https://dbugger85.github.io/shale-rush/

One `index.html`, no build step. Open `index.html#test` to run scripted balance checks.
